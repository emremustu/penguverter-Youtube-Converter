# 🐧 Penguverter

YouTube Video & Audio Converter (MP3 / MP4) built with Electron + React.

---

## 🇹🇷 Türkçe

### 📌 Nedir?

Penguverter, YouTube videolarını kolayca indirip **MP3 (ses)** veya **MP4 (video)** formatına çevirmenizi sağlayan basit bir masaüstü uygulamasıdır.

---

### ✨ Özellikler

* 🎵 MP3 olarak indirme
* 🎬 MP4 olarak indirme
* ⏱ Başlangıç & bitiş aralığı seçme (clip alma)
* 📁 Klasör seçebilme
* 🏷 Dosya adı belirleme
* ⚡ Hızlı ve sade arayüz

---

### 📥 Nasıl Kullanılır?

1. **Uygulamayı indir**

   * Sağ taraftaki **Releases** bölümünden `.exe` dosyasını indir

2. **Uygulamayı aç**

3. **YouTube linkini yapıştır**

4. (Opsiyonel) **Başlangıç ve bitiş süresi gir**

   * Örnek: `00:30` veya `01:02:10`

5. **Format seç**

   * MP3 → Ses
   * MP4 → Video

6. **Klasör seç**

7. **İndir butonuna bas** 🚀

---

### ⚠️ Notlar

* İlk açılışta Windows güvenlik uyarısı verebilir

  * "More info" → "Run anyway"
* Sadece YouTube linkleri desteklenir

* Embedded iframede 153 hatası verse de sorunsuz çalışıyor sadece iframede çözemediğim bir hata oldu. Diğer versiyonlarda çözmeyi düşünüyorum

## 🇬🇧 English

### 📌 What is this?

Penguverter is a simple desktop application that allows you to download YouTube videos as **MP3 (audio)** or **MP4 (video)**.

---

### ✨ Features

* 🎵 Download as MP3
* 🎬 Download as MP4
* ⏱ Select start & end time (clip extraction)
* 📁 Choose download folder
* 🏷 Custom file name
* ⚡ Fast and minimal UI

---

### 📥 How to Use

1. **Download the app**

   * Go to the **Releases** section and download the `.exe`

2. **Open the application**

3. **Paste a YouTube URL**

4. (Optional) **Enter start and end time**

   * Example: `00:30` or `01:02:10`

5. **Select format**

   * MP3 → Audio
   * MP4 → Video

6. **Choose a folder**

7. Click **Download** 🚀

---

### ⚠️ Notes

* Windows may show a security warning on first run

  * Click "More info" → "Run anyway"
* Only YouTube URLs are supported
